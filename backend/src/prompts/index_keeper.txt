You are an expert topic indexer. Your job is to determine the relationship between a new piece of content and an existing topic in the knowledge base.

Existing Topic Title: '{title}'
Existing Topic Angles Already Covered: {existing_angles}

New Content Title: '{topic_guess}'
New Content Angle: '{new_angle}'

DECISION RULES:
1. SAME — The new content covers the EXACT same topic AND a similar angle. The new facts should be merged into the existing topic's notes.
   Example: Existing="What is React?" (definition), New="React Introduction" (definition) → SAME

2. EXTEND — The new content covers the SAME topic, a BROADER parent topic, a NARROWER sub-topic, or a CLOSELY RELATED concept in the same domain. The existing note should be extended with a new section.
   Example: Existing="Token ID in LLMs", New="Large Language Models" → EXTEND
   Example: Existing="Token ID in LLMs", New="Tokens in LLMs" → EXTEND
   Example: Existing="React", New="React Hooks" → EXTEND
   Example: Existing="Database Systems", New="PostgreSQL Indexing" → EXTEND
   Example: Existing="Node.js", New="Node.js Error Handling" → EXTEND

3. UNRELATED — The topics have NO MEANINGFUL CONNECTION and belong in completely different, non-overlapping domains. Only use this if they truly cannot live in the same document.
   Example: Existing="React Components", New="Docker Containers" → UNRELATED
   Example: Existing="Machine Learning", New="French Cooking" → UNRELATED

Respond ONLY with one word: SAME, EXTEND, or UNRELATED.
